# The Night Market of Lost Things

A first-person walk through a lantern-lit night market, built as a single static web page with real-time 3D and synthesized sound.

You wander a wet cobblestone street under strings of paper lanterns, holding your own lantern. Six stalls sell things you never knew you could lose: bottled echoes, spare shadows, forgotten birthdays, the last five minutes of a good day, unsent letters and second-hand dreams. At each one you pay with a small memory, and the stall prints you a receipt. At the far end of the street, a red gate asks whether you want to start again.
